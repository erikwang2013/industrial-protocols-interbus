# INTERBUS 协议包 — 需 Phoenix Contact IBS 桥接

> [English](README.en.md)

INTERBUS (INTERBUS-S) 现场总线协议。需要 Phoenix Contact IBS 接口模块，通过内核 Bridge 层桥接。

## 安装

```bash
composer require erikwang2013/industrial-protocols-interbus
```

## 功能

INTERBUS 桥接、BridgeConnector 连接管理

## 所需硬件

Phoenix Contact IBS 接口模块

## 兼容框架

Laravel / Webman / Hyperf / ThinkPHP / Yii2 / Yii3 / Plain PHP

## 系统要求

- PHP >= 8.1
- INTERBUS 接口模块
- erikwang2013/industrial-protocols-kernel
